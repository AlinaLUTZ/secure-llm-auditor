# 🛡️ ИБ-Аудитор ИИ-Систем

CLI-инструмент на Python для автоматизированного аудита текстовых данных на соответствие требованиям законодательства РФ (ФЗ-152, Постановление №19/2024, ГОСТ Р 57580.2) при использовании генеративных моделей ИИ.

## 🚀 Функционал
- **Детекция ПДн:** Поиск ФИО, паспортов, СНИЛС, ИНН, биометрии.
- **Классификация:** Определение уровня защищенности ИСПДн (по Пост. №1119).
- **Анонимизация:** Автоматическая замена чувствительных данных на маркеры.
- **Compliance Check:** Проверка безопасности промпта перед отправкой в LLM.
- **Отчетность:** Генерация отчетов (MD/PDF) и ведение журнала аудита (`audit.log`).

## 🛠️ Стек технологий
- Python 3.10+
- Regular Expressions (Regex)
- FastAPI (для будущей веб-версии)
- Docker (для контейнеризации)
